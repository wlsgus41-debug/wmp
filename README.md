# 🎵 모든 세계의 노래 (World Music Player)

유튜브 기반의 전 세계 모든 장르 음원 재생, 영상 없는 미니멀 앨범 아트 썸네일 뷰어, 멜론/지니/벅스/유튜브뮤직 실시간 차트 사이드바, 다중 플랫폼(멜론, 지니, 스포티파이, 플로 등) 실시간 싱크 가사를 지원하는 올인원 웹 음악 플레이어입니다.

---

## ✨ 주요 기능

1. **유튜브 음원 백그라운드 재생 & 썸네일 전용 UI**
   - 영상 대신 고화질 앨범 아트 썸네일 및 감성적인 회전 바이닐(LP) 비주얼라이저 제공
   - 백그라운드 YouTube 오디오 엔진 연동 (오디오 끊김 없이 부드러운 재생)

2. **실시간 차트 사이드바 (Side Menu)**
   - **멜론 TOP 100**, **지니 TOP 100**, **벅스 실시간 차트**, **유튜브 뮤직 인기곡** 실시간 제공
   - 차트 곡 클릭 한 번으로 자동 유튜브 음원 매칭 및 즉시 재생
   - 대기열(+) 추가 기능 지원

3. **다중 플랫폼 실시간 싱크 가사 (Lyrics View)**
   - **스포티파이 / LRCLIB** 기반 실시간 싱크(타임코드) 가사 하이라이팅 및 자동 스크롤
   - **멜론, 지니, 벅스, 플로, 유튜브뮤직** 출처별 가사 선택 탭 지원
   - 가사 줄 클릭 시 해당 재생 시간으로 즉시 이동 (Seek)
   - 전체 가사 텍스트 모드 전환 지원

4. **모든 장르 유튜브 검색 & 대기열 관리**
   - K-POP, 팝송, 힙합, 발라드, 재즈/Lo-Fi, 애니/OST, J-POP 등 장르 퀵 필터
   - 유튜브 실시간 검색어 자동 매칭 및 곡 추가
   - 재생 대기열(Queue) 관리, 셔플, 반복 재생(한곡/전체), 볼륨 컨트롤

---

## 🚀 실행 방법

### 1. 백엔드 서버 실행
```bash
cd server
npm install
npm start
```
> 백엔드 서버가 `http://localhost:3001`에서 실행됩니다.

### 2. 프론트엔드 클라이언트 실행
```bash
cd client
npm install
npm run dev
```
> 브라우저에서 `http://localhost:8080`으로 접속하면 플레이어를 사용할 수 있습니다.
